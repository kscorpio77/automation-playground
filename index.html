Automation Testground

A small, static practice site for writing browser automation scripts (Selenium, Playwright, Cypress, Puppeteer, etc). Every interactive element carries a stable data-testid attribute that will not change within this major version, so scripts you write against this version keep passing.

Forms & Validation

Text fields, dropdowns, checkboxes, radios, client-side validation errors.

Dynamic Content & Waits

Spinners, delayed elements, buttons that enable after a delay, progress bars.

Tables & Data

Sortable columns, search filtering, pagination over a static dataset.

Modals & Alerts

Native alert/confirm/prompt dialogs, a custom modal, and a hover tooltip.

Drag, Drop & Upload

Drag-and-drop between lists, a file input, and an embedded iframe.

Mocked Login Flow

Login form, a protected dashboard page, and logout — state kept in localStorage.
