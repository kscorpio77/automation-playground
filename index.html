Automation Playground

A friendly, hands-on browser automation training site. Practise everyday controls, synchronization, accessible locators, and realistic user journeys with plain HTML, CSS, and JavaScript.

For Selenium, Playwright, Cypress, WebdriverIO, Puppeteer, Robot Framework, and other browser tools.

Quick start with Docker

Shell
git clone https://github.com/kscorpio77/automation-playground.git
cd automation-playground
docker build -t automation-playground:1.3.0 .
docker run --rm -p 8080:80 automation-playground:1.3.0
